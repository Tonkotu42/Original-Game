# Unity Game Scripts

Unityで制作中のゲームのC#スクリプト集です。

## 収録スクリプト一覧

* **`WeaponCollider.cs`**
  * 武器の当たり判定（Collider）の有効化・無効化を切り替えるスクリプト[cite: 2]。
* **`TitleScreen.cs`**
  * タイトル画面のUIボタン操作からメインゲームシーン（`Scene 1`）へ遷移するスクリプト[cite: 4]。
* **`StageManager.cs`**
  * 次の難易度のステージ（`Scene2`）へのシーン遷移を管理するスクリプト[cite: 8]。
* **`StatusWindowManager.cs`**
  * プレイヤーのステータス（HP, MP, Attack, Defence）をTextMeshProのUIウィンドウにリアルタイム反映するスクリプト[cite: 6]。
* **`SaveManager.cs`**
  * `PlayerPrefs` を使用してプレイヤーの現在HPをセーブするスクリプト[cite: 10]。
